# Вариант 04. Модернизация учёта оборудования

**СТАРТОВЫЙ ПРОЕКТ ДЛЯ СТУДЕНТА**

**Покрываемые темы:** Legacy code, Adapter, LINQ, параллелизм, lock, реестр, DLL

## Условия зачёта

Выполнить 7 обязательных заданий. Дополнительные задания повышают оценку. Код должен собираться на .NET 9.
Не допускаются пустые `catch`, блокирующие ожидания в UI-потоке и небезопасное совместное изменение состояния.

## Обязательные задания
1. Проанализировать стартовый legacy-код и найти три дефекта.
2. Вынести повторяющуюся логику поиска в отдельный сервис.
3. Создать Adapter для старого формата карточки оборудования.
4. Добавить фильтрацию оборудования через LINQ.
5. Реализовать безопасное изменение остатка при параллельных операциях.
6. Сохранять выбранный фильтр и тему интерфейса в HKCU.
7. Вынести модель и сервис в Class Library.

## Дополнительные задания
8. Добавить журнал изменений.
9. Добавить асинхронное сохранение отчёта.
10. Добавить номер версии схемы настроек.

## Требования к сдаче

- Сохранить комментарии `TODO` и заменить их реализацией.
- Добавить отдельные классы для моделей и сервисов.
- Приложить 3–5 тестовых сценариев или пошаговую инструкцию проверки.
- Подготовить устное объяснение архитектуры и одного исправленного дефекта.

## Запуск

```powershell
dotnet restore
dotnet build
dotnet run
```
